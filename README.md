# TechNexus 2.0

Portal local full-stack leve para Termux/Node.js.

## Iniciar
npm install
npm start
Abra http://localhost:3000

## Admin
Abra http://localhost:3000/admin.html
Chave local padrão: technexus-local-admin

Para produção, defina ADMIN_KEY no ambiente do servidor. Os campos de Smart Link, Telegram e anúncios são configurados no painel.
